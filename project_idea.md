## 1 Project Idea: Benchmarking the Evaluators - AST vs. LLM-as-a-Judge

### 1.1 Motivation and Uniqueness Argument
Modern generative AI evaluation increasingly relies on dynamic, adversarial creativity benchmarks, such as Denial Prompting, to counteract mode collapse and the suppression of distributional diversity in aligned language models. These state-of-the-art paradigms attempt to elicit out-of-the-box, divergent thinking by iteratively imposing rigid algorithmic constraints (e.g., forbidding the use of for loops or recursion). However, a profound epistemological crisis has emerged in the meta-evaluation of these frameworks: the deep over-reliance on the "LLM-as-a-Judge" (LLM-aaJ) architecture. Current benchmarks utilize probabilistic language models to extract variables, analyze generated code, and verify rule compliance. This methodological choice introduces an unmeasured, probabilistic hallucination rate into what should fundamentally be a deterministic mathematical evaluation. Utilizing a probabilistic text-generation engine to enforce and score rigid, binary structural constraints fatally compromises the scientific integrity of the benchmark.

This project introduces a methodological pivot: replacing the probabilistic LLM-as-a-Judge with deterministic Abstract Syntax Tree (AST) parsing to audit these frameworks. While AST parsing is a traditional compiler concept, applying it as a meta-evaluation tool to quantify the exact epistemological error rate of modern AI evaluation frameworks is a highly novel academic intervention. By replacing the probabilistic extraction of algorithmic techniques with a deterministic parsing function, this project will establish an infallible ground truth to benchmark the evaluators themselves.

### 1.2 AST Versus Embeddings Justification
A frequent counter-argument posits that high-dimensional semantic embeddings (such as DeBERTa-v3-large) possess sufficient latent reasoning power to render deterministic parsers obsolete, given their success in equivalence classification. This project addresses this by empirically proving that semantic embeddings and structural parsing are strictly orthogonal and complementary.

Embeddings measure Functional Equivalence. They excel at projecting contextual meaning into a latent space to evaluate whether two solutions solve the same mathematical problem and provide identical end-user utility. Conversely, AST parsing measures Structural Compliance. Adversarial creativity benchmarks rarely impose functional constraints; they impose structural ones. If two code fragments arrive at the identical functional answer but one uses a banned loop and the other uses allowed recursion, their semantic embeddings remain highly similar, ignoring the constraint violation. Embeddings mathematically perform semantic smoothing, abstracting away the precise architectural syntax required to enforce adversarial algorithmic boundaries. Therefore, embeddings cannot reliably enforce rigid constraints. We must prove that deterministic AST parsing is required alongside semantic embeddings.

### 1.3 Concrete Execution Plan (2 Months)
To empirically prove the necessity of AST parsing and to quantify the failure rates of LLM-as-a-judge frameworks, the following exhaustive data-analysis pipeline will be executed. This pipeline is purely comparative and minimizes compute bottlenecks.

1. **Weeks 1-2: Data Ingestion and Ground Truth AST Parsing.** Load the existing 5,970 correct human solutions across 199 problems from the NeoCoder dataset. Because these solutions are guaranteed to be functionally correct, the analysis bypasses functional execution entirely. A lightweight Python script utilizing the native `ast.NodeVisitor` module will be engineered to traverse the syntax tree of every solution. The visitor will deterministically detect a targeted subset of 5-10 atomic techniques (e.g., recursion, list comprehensions, while loops). This establishes our 100% accurate structural ground truth matrix.
2. **Weeks 3-4: LLM-as-a-Judge Evaluation.** Feed the exact same 5.9K human solutions to an open-weights LLM, specifically Llama-3-8B-Instruct, via a local execution environment or free-tier inference API. Prompt the LLM to identify the techniques used in the code, mirroring the zero-shot extraction parameters of existing benchmarks. Log the LLM's classification accuracy, False Positives (hallucinations), and False Negatives against the AST ground truth to quantify the exact epistemological error rate.
3. **Weeks 5-6: Embedding vs. Structure Analysis.** Pass the solutions through the `microsoft/deberta-v3-large` classifier to generate functional embeddings. Perform a comparative analysis highlighting specific instances of "Semantic Collision with Structural Divergence"—pairs of solutions that are functionally identical in the embedding space (high cosine similarity) but vastly different in their AST structures. This statistical proof will demonstrate that high cosine similarity has near-zero correlation with structural compliance, proving embeddings alone cannot enforce algorithmic constraints.
4. **Weeks 7-8: Reporting.** Calculate the final error margins of the LLM-as-a-judge by recalculating historical creativity scores. Replace the probabilistic technique scores assigned by the LLM with the deterministic scores assigned by the AST parser. Draft the final report demonstrating that automated creativity evaluations in rule-bound domains require a dual-axis approach: deterministic structural parsing alongside semantic embeddings.

### 1.4 Feasibility
This proposed project is exceptionally feasible and highly optimized for a strict two-month academic timeline. By leveraging the pre-existing repository of 5.9K verified human solutions from the NeoCoder dataset, the pipeline completely bypasses the compute-heavy, time-consuming process of generating new code with LLMs. The analytical pipeline relies strictly on highly optimized, mathematically deterministic Python parsing, free-tier inference APIs, and local data analysis. The central ground truth is established through deterministic parsing rather than subjective human annotation or probabilistic machine learning, ensuring that the results of the primary hypothesis are mathematically guaranteed within the timeframe, regardless of model behavior.
